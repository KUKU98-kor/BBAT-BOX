# BBAT BOX

모바일과 아이패드에서 사용할 수 있는 야구 경기 기록지 인터랙티브 초안입니다.

## 확인 방법

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도의 설치 과정은 없습니다.

- 고정 하단 메뉴: HOME, 리그기록, 팀 관리, 캘린더, LIVE
- 소속 팀 선택에 따라 달라지는 개인 시즌 기록
- 리그별 편집 권한과 보기 전용 상태 표시
- 팀 정보, 최근 출전 선수, 다음 경기 일정
- 여러 팀의 통합 캘린더와 개인 야구 노트
- 경기장 미니맵을 포함한 실시간 경기 상황판
- 항상 접근할 수 있는 프로필 및 설정 메뉴

현재 버전은 전체 정보 구조와 화면 이동 흐름을 확인하는 베타 초안입니다. 계정 로그인, 초대 가입, 팀 역할과 계정 상태는 Supabase 서버에 저장됩니다. BBAT BOX 전체 호스트는 한 명이며, 각 팀 방의 관리자·매니저·기록원 등 수정 권한자는 호스트를 제외하고 최대 5명으로 제한됩니다.

호스트가 처음 로그인하면 빈 시작 화면에서 직접 팀 방을 만듭니다. 팀 방을 만든 뒤 계정 초대코드를 발급하거나, 앱을 사용하지 않는 선수를 이름·등번호·포지션만으로 명단에 등록할 수 있습니다.

경기 기록, 일정, 라인업 등 기존 베타 데이터 일부는 아직 브라우저별 저장소를 사용합니다. 여러 팀원이 같은 경기 기록을 동시에 사용하는 단계에서는 이 데이터도 Supabase 테이블과 실시간 구독으로 순차 전환합니다.

테스트 배포 준비와 서버 전환 순서는 [DEPLOYMENT.md](DEPLOYMENT.md), 팀원 테스트 항목과 수정사항 전달 양식은 [TESTING.md](TESTING.md)를 확인하세요.

## 저장소 구분
