# BBAT BOX

BBAT BOX는 팀 운영, 경기 일정, 참가 투표, 라인업, 야구 기록지와 LIVE 상황판을 한곳에서 사용하는 모바일 중심 야구팀 관리 앱입니다.

## 정식 서비스

- 서비스 주소: <https://kuku98-kor.github.io/BBAT-BOX/>
- 현재 버전: `v1.0.0`
- 운영 브랜치: `main`
- 개발 브랜치: `beta`
- 서버: Supabase 인증·데이터베이스·스토리지·실시간 구독

같은 주소를 휴대전화와 태블릿에서 사용할 수 있습니다. 브라우저의 **홈 화면에 추가** 기능을 사용하면 일반 앱처럼 실행됩니다.

## 주요 기능

- 회원가입, 로그인, 프로필과 프로필 사진 관리
- 팀 생성, 공용 참가코드, 가입 승인과 역할 지정
- 호스트 1명과 최대 5명의 팀 수정 권한자 관리
- 앱을 사용하지 않는 선수를 포함한 선수 명단 관리
- 일정 등록, 참가 투표, 라인업 작성
- 타자·투수·주루가 연결된 경기 기록지
- 기록과 연동되는 LIVE 경기 상황판
- 개인에게만 보이는 야구 노트
- 팀·리그·경기 데이터를 여러 기기에서 공유

비밀번호 원문은 운영자에게 공개되지 않으며 Supabase 인증 시스템이 안전하게 검증합니다. 서비스 역할 키와 운영 비밀값은 공개 저장소에 넣지 않습니다.

배포 및 업데이트 절차는 [DEPLOYMENT.md](DEPLOYMENT.md), 점검과 오류 제보 방법은 [TESTING.md](TESTING.md), 버전별 변경사항은 [CHANGELOG.md](CHANGELOG.md)를 확인하세요.

## 저장소 구분

이 저장소에는 공개 가능한 앱 화면과 클라이언트 코드만 보관합니다. 민감한 운영 문서와 비공개 설정은 별도의 비공개 저장소 `BBAT-BOX-P`에서 관리합니다.
