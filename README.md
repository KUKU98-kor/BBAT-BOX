# BBAT BOX

모바일과 아이패드에서 사용할 수 있는 야구 경기 기록지 인터랙티브 초안입니다.

## 확인 방법

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도의 설치 과정은 없습니다.

- 고정 하단 메뉴: HOME, 리그기록, 팀 관리, 캘린더, LIVE
- 소속 팀 선택에 따라 달라지는 개인 시즌 기록
- 리그별 편집 권한과 보기 전용 상태 표시
- 팀 정보, 최근 출전 선수, 다음 경기 일정
- 여러 팀의 통합 캘린더와 개인 야구 노트
- 경기장 미니맵을 포함한 실시간 경기 상황판
- 항상 접근할 수 있는 프로필 및 설정 메뉴

현재 버전은 전체 정보 구조와 화면 이동 흐름을 확인하는 초안입니다. 실제 계정 권한, 여러 기기 간 데이터 동기화, 기록 입력 및 실시간 중계는 다음 단계에서 서버와 연결해야 합니다.

## 저장소 구분

이 저장소에는 공개 가능한 사용자 화면만 보관합니다. 관리자 권한 정책, 데이터베이스 설계와 운영 설정은 별도의 비공개 저장소 `BBAT-BOX-P`에서 관리합니다.
