# BBAT BOX

모바일과 아이패드에서 사용할 수 있는 야구 경기 기록지 인터랙티브 초안입니다.

## 확인 방법

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도의 설치 과정은 없습니다.

- 1~9번 타자 선택
- 선수별 최대 10타석 및 주루 기록
- 투구별 볼, 지켜본 스트라이크, 헛스윙, 파울, 인플레이 입력
- 안타, 홈런, 볼넷, 삼진 등 타격 결과 선택
- 타점, 득점, 도루, 주루 메모 저장
- 마지막 기록 되돌리기
- 브라우저에 임시 자동 저장

현재 버전은 화면과 입력 흐름을 확인하는 초안입니다. 실제 계정 권한, 여러 기기 간 데이터 동기화, 상대 팀 라인업 및 선수 교체 저장은 다음 단계에서 서버와 연결해야 합니다.

## 저장소 구분

이 저장소에는 공개 가능한 사용자 화면만 보관합니다. 관리자 권한 정책, 데이터베이스 설계와 운영 설정은 별도의 비공개 저장소 `BBAT-BOX-P`에서 관리합니다.
